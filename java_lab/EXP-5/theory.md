# Experiment 5: Packages

## Aim
To perform arithmetic operations and calculate shape measurements using Java packages.

## Exercises

- `5.a`: Arithmetic operations using `add`, `sub`, `mul`, and `div` packages.
- `5.b`: Perimeter and area of a square, circle, and triangle using the `Shape` package.

## Result
The package-based arithmetic and shape programs were compiled and executed successfully.
# Reference-compatible programs

The reference repository's standalone `ArithmeticOperations.java` and
`PerimeterAndArea.java` are also provided at this level. The original
package-based exercises in `5.a` and `5.b` are retained unchanged.
