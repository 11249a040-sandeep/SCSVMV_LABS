# Experiment 3: Number Programs

## Aim
To write Java programs for Armstrong numbers, Fibonacci series, multiplication tables, perfect numbers, and reversing a number.

## Theory
An Armstrong number equals the sum of its digits raised to the number of digits. The Fibonacci series begins with zero and one, with each later term equal to the sum of the previous two terms. A multiplication table is generated by repeated multiplication. A perfect number equals the sum of its proper divisors. Reversal is formed by repeatedly taking the last digit and shifting the current result left by one decimal place.

## Algorithm

1. Read the number or number of terms.
2. Extract digits with `% 10` and reduce the number with `/ 10` where required.
3. Generate Fibonacci terms iteratively from the previous two terms.
4. Add proper divisors to test perfection.
5. Build the reverse using `reverse = reverse * 10 + remainder`.
