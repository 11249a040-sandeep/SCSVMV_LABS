# Experiment 7.a: Account Details Using Inheritance

## Aim
To demonstrate account operations and interest-rate details using inheritance.

## Theory
`SBAccount` extends `Account`, reusing its credit, debit, and balance methods while adding an interest-rate field.

## Programs
`Account.java`, `SBAccount.java`, and `AccountDemo.java`.

## Result
The account balance was updated and the interest rate was displayed successfully.
