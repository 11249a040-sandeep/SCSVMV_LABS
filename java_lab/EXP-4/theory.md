# Experiment 4: String Processing

## Aim
To generate substrings of a string and replace selected text using Java string methods.

## Theory
A Java `String` is an immutable sequence of characters. `substring(begin, end)` returns the characters from the beginning index up to, but excluding, the end index. Every non-empty contiguous substring can be generated by choosing a start position and an end position. The `replace` method returns a new string with matching text replaced; the original string is unchanged.

## Programs

| Exercise | Source file |
| --- | --- |
| Substrings of a string | [`SubstringsOfAString.java`](SubstringsOfAString.java) |
| Replacing a string | [`Replace.java`](Replace.java) |

## Algorithm

1. Read the complete input string.
2. Select each character position as a start position.
3. Extend the end position one character at a time and print each substring.
4. Read the text to replace and its replacement.
5. Call `replace` and print the updated string.

```text
A
No of substrings present are: 10
Updated string: I like Java programming
```

## Result
The required substrings were generated and the selected text was replaced successfully.
